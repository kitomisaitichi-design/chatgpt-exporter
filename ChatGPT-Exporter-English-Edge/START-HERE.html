No code, token, or API key to paste. This folder is the complete Edge extension.

Updating from 2.2

Pause the exporter, replace the files inside the same installed extension folder, open edge://extensions, and click Reload. Do not uninstall/reinstall: v2.3 deliberately keeps the same IndexedDB database name, so your discovered IDs, cached chats, cursors, cooldown and queue can survive the update.

Fresh install

  1. Keep this extracted folder somewhere permanent.
  2. Open edge://extensions, enable Developer mode, choose Load unpacked, and select this folder.
  3. Open the exporter, connect ChatGPT, choose the backup folder, and start.

New in 2.4.9

Choose an existing backup root or its parent: the exporter detects and reuses matching contents. Nested/renamed transcript JSON, prior indexes and verified native-ID/hash file copies are recognized. Documents, Downloads and Desktop shortcuts, remembered permitted folders, scan results and Rescan local folders make local recovery visible.

Restarts now handle chat attachments without native file IDs. Null metadata no longer interrupts file queue or Library sorting. Reload this same folder and resume the existing backup.

Ready files download during Library discovery. Chat text, attachment batches, Library work and local validation take fair turns. Slow discovery shifts more turns to downloads. The dashboard explains the active queue, growth and waits. Each attachment batch preserves its position, and the existing hash/source-history/image controls remain compatible with current Viewer 1.1.7.
