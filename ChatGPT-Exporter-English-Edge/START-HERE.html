No code, token, or API key to paste. This folder is the complete Edge extension.

Updating from 2.2

Pause the exporter, replace the files inside the same installed extension folder, open edge://extensions, and click Reload. Do not uninstall/reinstall: v2.3 deliberately keeps the same IndexedDB database name, so your discovered IDs, cached chats, cursors, cooldown and queue can survive the update.

Fresh install

  1. Keep this extracted folder somewhere permanent.
  2. Open edge://extensions, enable Developer mode, choose Load unpacked, and select this folder.
  3. Open the exporter, connect ChatGPT, choose the backup folder, and start.

New in 2.4.5

Large backups use cached rendering and indexed file lookups. Large All lists show 500 rows per page. The six-minute activity checkbox works during a run, remembers On/Off, and shows a countdown. Chat attachments and Library items share verified downloads by file ID and SHA-256. Separate source history and saved files remain when a chat or Library reference disappears. New transfers must be under 10 MB; larger items stay listed for manual access. Choose image downloads, inspect source filters, and use Files & Library in the current Viewer 1.1.6.
