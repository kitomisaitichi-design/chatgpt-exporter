# Demo assets

All four GIFs show the real v2.4.17 dashboard at 1600 × 1000 using fictional sample conversations and file catalog entries in an isolated Edge profile. No user account data, credentials or private filenames are included. Playback is edited and does not measure download speed.

The backup fixture writes 80 cached sample conversations through the real engine without conversation-detail requests. Library statuses illustrate search, views, manual filters and image preference; they do not demonstrate real remote file transfers. Update metadata is a simulated newer official release. The demo shows the silent-install setting, not an actual release installation. Activity records are synthetic.
