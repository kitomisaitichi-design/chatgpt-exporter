# ChatGPT Exporter 2.4.25

Open **Library** and enable **Prioritize archives up to 125 MB**. The setting starts off and is saved per account. ZIP, RAR, 7z, TAR and common compressed variants qualify by filename. Both Library files and chat attachments can use the inclusive decimal 125 MB cap.

Eligible archives move ahead during file turns. Chat turns, network cooldowns and retry limits still apply, and every fourth Library file turn is oldest first. Turning the setting on reopens eligible size skips. Turning it off puts unsaved oversized archives back in the manual list and keeps downloaded copies available.

Reload the existing extension card in Edge, refresh the dashboard and enable the toggle before starting or resuming the backup.
