# ChatGPT Exporter 2.4.1

Library reliability, fewer disk writes, and integration with [Offline Chat Viewer 1.1.4](https://github.com/kitomisaitichi-design/chatgpt-viewer/releases/tag/v1.1.4).

- Automatically save Library files strictly below 10,000,000 bytes. Larger files have a manual catalog, source links and stable expected backup paths.
- Viewer Files & Library displays saved files, source chats and manual downloads, and imports a manually downloaded copy directly into the backup.
- Preserve complete metadata during sparse observations; resume interrupted pagination; reject false completion after repeated pages or a folder limit.
- Cancel oversized transfers; honor Stop/hold between chunks; check existing saved Library copies on resume.
- Skip unchanged catalog writes, batch changing catalogs, and improve paused/cleared log behavior.

Update the existing unpacked extension folder, reload its card at edge://extensions, reload the connected ChatGPT tab, and reopen the dashboard. Keep the same extension and backup folders to preserve saved progress. Update/restart the viewer while keeping .viewer-data.

Validated with 54 exporter regression tests, 162 Viewer backend tests and an isolated Edge integration test. Website responses were simulated; live-account Library compatibility has not been verified. Passive checks run while the dashboard and signed-in ChatGPT tab remain open.
